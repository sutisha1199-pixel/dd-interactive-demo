# Gogo interactive demo

Jackpot Lotto：直接打开 [lottery.html](lottery.html)，或从大厅 Promo → Jackpot Lotto 进入。印度版使用 English (India)、INR 印度数字分组和 IST（UTC+05:30）。支持手动领券、跨日结算、按券无放回抽奖、结果榜单、手动领奖、后台配置和开奖审计。详细规则见 [玩法与开奖说明](docs/Jackpot-Lotto-玩法与开奖说明.md)，研发拆解见 [研发需求文档](docs/Jackpot-Lotto-研发需求文档.md)。所有支付、投注、中奖、余额均为本地模拟数据。
直接打开 index.html 即可运行，无需安装依赖。页面美术素材裁剪自提供的参考图。

支持：首页分类、游戏试玩、体育竞猜演示、充值、提现、提现审核、手机号绑定、银行卡、活动领奖、兑换码 DEMO100、每日转盘、资产记录、站内信与客服。数据保存于浏览器 localStorage，全部为模拟数据，不接入真实支付或投注。

手机号演示验证码：123456。顶部更多按钮进入后台演示入口。
功能清单中的归因、风控、域名轮询、第三方系统等需要服务端和真实供应商才能接通；本 demo 提供对应入口，不代表已完成集成。

## 第二版交互
- 前台：充值金额与通道、银行卡校验、提现申请、首/次/三充及累充门槛、VIP、任务、排行榜、代理佣金、邀请抽奖、客服对话、消息已读状态、订单筛选。
- 后台：通道开关、人工资产调整、提现批量拒审与冲正、转盘奖励审核、游戏上下架/维护/排序、风控条件、活动发布、消息投递、标签、归因事件、版本/域名配置、账号生成。
- 后台部分操作会直接影响前台，数据仍仅存在当前浏览器。
- AF/Adjust、三方支付、短信识别、推送、灰度分流、第三方客服与域名健康探测未接入真实服务；部分控制台为配置演示。
- come.com 尚未访问核实：浏览器自动审批服务返回模型不支持，操作被阻止。

## Earn 代理中心
底部 Turntable 已替换为 Earn，大厅布局保留。代理中心包含：
- My rewards / Invite rewards / Rules；俱乐部等级、代理可提现收益、累计及今日收益。
- 代理奖励转入主钱包与提现记录，金额校验和重复提交保护。
- 团队 Overview / Details / Subordinates；团队范围、日期范围、Tier 1–3、玩家搜索、13种排序。
- 新玩家/存量玩家/首充数据，个人与团队充值、下注、佣金指标。
- 奖励记录按 Bet / Deposit / Invite / InviteTask 筛选。
- H5 底部抽屉处理日期、筛选、提现和邀请分享；支持系统分享与复制链接降级。
