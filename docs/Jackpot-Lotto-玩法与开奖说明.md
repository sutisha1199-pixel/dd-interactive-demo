# Jackpot Lotto 玩法与开奖说明

版本：2026-10-20 · 可交互原型

## 1. 本版规则
- 每日一期，按活动业务时区切分，Demo 默认 Asia/Kolkata；02:30 开启新一期。
- 单笔或累计充值达到后台配置金额后激活，激活仅当期有效；激活前充值和投注不追溯。
- 有效投注按后台配置的厂商和类型过滤，仅结算、未退款、未撤销金额计入。
- 投注档位按最高匹配档位计算，不叠加；券需手动领取，未领取券在02:25失效。
- 同一张券最多中奖一次；同一用户多张券可以中多个奖，合计一次领取。

## 2. 每日时间线
- D日02:30至D+1日02:25：参与中，激活、投注、手动领券。
- D+1日02:25至02:30：结算中，对账、锁定奖池和开奖库。
- D+1日02:30至D+2日02:30：开奖和领奖，登录自动弹榜，中奖者手动领取。
- D+2日02:30起：未领取奖金过期，历史结果保留。

## 3. 开奖过程
1. 02:25封存旧期：保留已领取券，未领取券和未达门槛进度失效；创建新期并冻结配置。
2. 02:25至02:30对账：排除取消、退款、重复和无效注单，锁定初始投入＋投注贡献奖池，保存候选券快照。
3. 按奖级顺序从剩余奖券中等概率无放回抽取；开奖库以期次＋券号唯一，同券不重复，同用户多券可多次中奖。
4. 02:30公布榜单，用户按期次一次领取全部中奖金额；领取请求幂等，不能重复入账。

## 4. 奖池逻辑
最终奖池 = 初始投入 + Σ（有效投注额 × (1 − 游戏RTP) × Jackpot拨款比例）。
示例：有效投注₹75,000,000、RTP 96%、拨款25%，贡献₹750,000；初始投入₹500,000，最终奖池₹1,250,000。大盘RTP按投注额加权计算。

## 5. 奖金比例
百分比表示该名次每个奖位获得总奖池的比例。总池₹1,250,000时，一等奖24%=₹300,000；二等奖每个4%=₹50,000；三等奖每个0.4%=₹5,000。后台校验奖级总分配不得超过100%。

## 6. Demo边界
Demo支持充值、投注、领券、时间推进、开奖库、榜单、领奖、后台配置、异常阻断和审计重算；数据保存在浏览器localStorage。生产需将调度、对账、随机源、钱包入账和审计迁移到服务端。
